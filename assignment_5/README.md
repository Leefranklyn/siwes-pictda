# Assigment 5 - Result Checker

## Description
This program accepts a student's name and score, it validates the score entered by the user, determines the student's performance and displays the appropriate result

## Objective
- Collect name and score from the user
- Validate the score value provided
- Determine grading based on the score provided 
- Display the output
