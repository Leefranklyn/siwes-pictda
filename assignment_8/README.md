# Assignment 8 - Student Management System

## Description
This program is a simple Student Management System that uses a list to store student names. The user is presented with a menu where they can add a student, remove a student, view all students, count the number of students, or exit the program. The program continues running using a loop until the user chooses the exit option.

## Objective
- Create a list to store student names
- Prompt the user to enter a student name and add it to the list
- Allow the user to remove a student from the list
- Display all students currently stored in the list
- Count and display the total number of students
- Allow the user to exit the program
