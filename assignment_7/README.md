# Assigment 7 - Number Guessing Game

## Description
This program generates a number randomly, has the user enter a value to try and guess the number within a set number of attempts. If the number provided by the user after 5 attempts doesn't match the grandomly generated number, the program ends and tell's the user the correct number. If the User guesses correctly within those 5 attempts the program breaks out from the loop and ends.

## Objective
- Generate a random number 
- prompt the user to enter a value which they think is the number
- Check to see if the provided value matches the generated number
- if all attempts are used without guessing the number,end the program
