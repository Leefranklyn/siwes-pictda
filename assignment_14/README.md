# Assignment 14 - Employee Payroll

## Description
This program is a simple Employee Payroll system that uses a class to store and manage employee payroll information. The program stores the employee's name, salary, tax, and bonus, then calculates the employee's gross salary, tax amount, and net salary.

## Objective
- Create an `Employee` class to store employee information
- Store the employee's name, salary, tax, and bonus
- Calculate the employee's gross salary
- Calculate the tax amount based on the employee's salary
- Calculate the employee's net salary after tax
- Display the employee's payroll information
- Use methods to perform the different payroll calculations
