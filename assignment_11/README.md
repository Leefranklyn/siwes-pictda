# Assignment 11 - Contact Book

## Description
This program creates a simple Contact Book using a list of dictionaries. Each dictionary stores information about a contact, including their name, phone number, and email. The user can add a contact, search for a contact by name, delete a contact, view all contacts, or exit the program.

## Objective
- Create a list to store contact dictionaries
- Add new contacts to the contact book
- Search for a contact by name
- Delete a contact from the contact book
- Display all contacts stored in the contact book
- Allow the user to exit the program
