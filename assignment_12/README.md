# Assignment 12 - Banking Application

## Description
This program is a simple Banking Application that uses a list of dictionaries to store and manage bank accounts. Users can create an account, check their balance, deposit money, withdraw money, transfer money to another account, or exit the program. The program uses functions, loops, and conditions to handle the different banking operations.

## Objective
- Create and store bank accounts using dictionaries
- Allow users to create a new account
- Allow users to check their account balance
- Allow users to deposit money into their account
- Allow users to withdraw money from their account
- Allow users to transfer money between accounts
- Use functions to organize the different banking operations
- Use loops and conditions to control the application
- Allow the user to exit the program
