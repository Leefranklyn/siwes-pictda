# Assignment 16 - Expense Tracker

## Description
This program is a simple Expense Tracker that uses a text file to store expense information. Users can add expenses, view all saved expenses, and calculate the total amount of all expenses stored in the file.

## Objective
- Store expenses inside a text file
- Allow users to add new expenses
- Save expense descriptions and amounts to the file
- Read and display saved expenses
- Calculate the total amount of all expenses
- Handle invalid expense amounts gracefully
- Use file handling to persist expense information
