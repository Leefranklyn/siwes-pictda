# Assigment 6 - Simple ATM Machine

## Description
This program accepts a student's name and score, it validates the score entered by the user, determines the student's performance and displays the appropriate result

## Objective
- Create an ATM menu with different option like check balance, deposit, withdraw
- Perform an operation based on the selected option by the user and display the output
