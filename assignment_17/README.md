# Assignment 17 - Virtual Environment

## Description
This assignment demonstrates how to create and use a Python virtual environment. The Requests library is installed inside the virtual environment, and the installed dependencies are saved in a `requirements.txt` file.

## Objective
- Create a Python virtual environment
- Activate the virtual environment
- Install the Requests library
- Freeze installed dependencies
- Create a `requirements.txt` file
- Use the virtual environment to run the program
