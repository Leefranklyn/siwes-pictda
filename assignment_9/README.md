# Assignment 9 - Shopping Cart

## Description
This program is a simple Shopping Cart system that uses a list to store products. The user is presented with a menu where they can add a product, remove a product, view all products in the cart, count the total number of products, or exit the program. The program continues running using a loop until the user chooses the exit option.

## Objective
- Create a list to store products
- Prompt the user to enter a product and add it to the list
- Allow the user to remove a product from the list
- Display all products currently stored in the list
- Count and display the total number of products
- Allow the user to exit the program
