# Assignment 13 - Library Management System

## Description
This program is a simple Library Management System that uses classes to represent books and manage the library. Users can add books, borrow books, return books, delete books, search for books, view available books, or exit the program. The system uses a `Book` class to store information about each book and a `Library` class to manage the books and borrowing operations.

## Objective
- Create a `Book` class to represent books in the library
- Create a `Library` class to manage the library's books
- Allow users to add new books
- Allow users to borrow books
- Allow users to return borrowed books
- Allow users to delete books from the library
- Allow users to search for books by title
- Display the books stored in the library
- Use classes and objects to organize the program
- Use functions, loops, and conditions to handle the different operations
