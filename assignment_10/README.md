# Assignment 10 - Dictionary

## Description
This program creates a simple student database using a list of dictionaries. Each dictionary stores information about a student, including their name, age, course, phone number, and email. The user can add student information and retrieve a student's information by entering their name.

## Objective
- Create a list to store student dictionaries
- Store a student's name, age, course, phone, and email
- Prompt the user to enter student information
- Search for a student by name
- Retrieve and display the matching student's information
- Allow the user to exit the program
