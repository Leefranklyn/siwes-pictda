# Assignment 15 - File Handling

## Description
This program manages student information using a text file called `students.txt`. The program allows users to create the file, add students, save student information to the file, read students from the file, and delete students. The program uses file handling operations to store student information so that it can persist after the program ends.

## Objective
- Create a `students.txt` file
- Add students to the program
- Save student information to the text file
- Read student information from the text file
- Delete students from the student list
- Use file handling to persist student information
- Handle missing files and invalid user input gracefully
- Use UTF-8 encoding when working with the text file
